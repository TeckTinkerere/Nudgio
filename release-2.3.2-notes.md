## What's new

- **Share now works.** Sharing a media item, a selection, or a backup from Nudgio failed before this version. It is fixed.
- **Share several files or folders at once.** Select media and folders in the Library and tap Share. One file is shared as it is. Two or more files, or any folder, are zipped automatically with your folder structure kept.
- **Save to gallery for a selection.** Select media and folders in the Library and tap Save to gallery. Copies go into a Nudgio folder in your photos, videos and music, and your Library folders become sub-folders. Saving the same selection again skips what is already there. Requires Android 10 or later.
- **Safer backups.** Backup files are now kept in Nudgio's private storage instead of a folder other apps and a connected computer could read, and only the newest one is kept.
- **Safer restore.** Restoring a backup now stops a media file that unpacks larger than it says, requires every media file to have a checksum, and rejects unexpected file names.
