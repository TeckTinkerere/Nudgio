## What's new

- **Alarms without an attachment.** You can now save a plain alarm with no photo, video or sound. It rings with your alarm sound from Settings, and shows Snooze and Dismiss. Add an attachment any time, or remove one with the new Remove attachment button.
- **Cleaner next-alarm and list views** for plain alarms: a clock instead of a picture placeholder, and no false "media isn't available" message.
- **Fix: "Not used by any reminder"** in Settings and the Library filter now stay correct when some alarms have no attachment.
- **Backups** keep plain alarms as they are, and backups from older versions still restore.

Before updating: this version changes Nudgio's database. Make a backup first (Settings, Back up), because an older version of Nudgio cannot open data saved by this one.
