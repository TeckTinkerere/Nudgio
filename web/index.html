Set it up

  1. 01

    Download the APK

    Tap the dial above. Your browser will flag it as an unrecognized file — that's expected for an app outside the Play Store.

  2. 02

    Allow this install

    Open the downloaded file. Android will ask to allow installs from your browser for this one app — approve it.

  3. 03

    Install and open

    Confirm the install, then open Nudgio and import your first reminder.

Why sideload is fine here

Nudgio isn't on the Play Store — it's built and signed by one person, published straight from source. The code is public on GitHub, every release is a tagged build, and each APK ships with a SHA-256 checksum you can verify against the file yourself.
